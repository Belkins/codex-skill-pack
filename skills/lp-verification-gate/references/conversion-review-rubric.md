# Conversion Review Rubric

Review findings in this order:

1. Blocking: user cannot understand, trust, or act.
2. High: mobile clipping, broken CTA, missing proof for core claim, pricing mismatch.
3. Medium: weak objection handling, generic copy, proof too low, visual mismatch.
4. Low: polish, copy tightening, minor alignment.

Every finding should include file/line or screenshot evidence and a concrete fix.
