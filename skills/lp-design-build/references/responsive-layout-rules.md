# Responsive Layout Rules

Test these widths unless the product requires more:

- 390: common small mobile.
- 430: larger mobile.
- 768: tablet.
- 1024: small desktop/tablet landscape.
- 1440: desktop.

## Fail Conditions

- Horizontal overflow.
- CTA text clipped or wrapping awkwardly.
- Fixed nav covers anchor targets.
- First viewport has no next-section hint on landing pages.
- Cards resize from hover/focus/async labels.
- Hero media overlaps heading or CTA.
- Touch targets under 44px on mobile.
