# Section Patterns

## Default High-Conversion Sequence

1. Hero: category, user moment, outcome, primary CTA, proof.
2. Product proof: interactive demo, screenshot, or concrete workflow.
3. Why now: pain of the current alternative.
4. How it works: three to five steps tied to the user's job.
5. Proof: testimonials, metrics, examples, or comparison evidence.
6. Offer: price/trial/demo terms and risk reversal.
7. Objections: FAQ or trust block.
8. Final CTA: same primary action as hero.

## Segment Page Sequence

1. Name the high-intent moment.
2. Show the exact scenario or outcome.
3. Demonstrate the product loop.
4. Handle risk and trust.
5. Convert.

Use this when the homepage is too broad for a single promise.
