# CTA Taxonomy

## Primary CTA

The single conversion action the page is judged on:

- Create free account
- Try voice demo
- Book demo
- Start assessment
- Join waitlist
- Buy now
- Start audit

## Secondary CTA

Supports evaluation without competing:

- Watch demo
- See example
- Compare plans
- Read proof
- Download app
- Listen first

## Rules

- Use one primary CTA label per page.
- Repeated primary CTA instances are acceptable.
- Secondary CTA should not be visually stronger than the primary.
- Avoid generic "Get Started" when a more specific action exists.
