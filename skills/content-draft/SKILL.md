# Content Draft

Create content from current work context.

## Instructions

### Step 1 — Parse Arguments

From `$ARGUMENTS`, extract:
- **Format:** linkedin, newsletter, or blog (default: linkedin)
- **Topic:** the subject to write about

### Step 2 — Gather Source Material

Review recent context:
- Git log (last few commits) for what was built
- Current files being worked on
- Conversation context for insights and decisions
- Memory files for broader project context

### Step 3 — Draft Content

#### LinkedIn Post Format
- Hook (first line must grab attention — no "I just..." openers)
- 3-5 short paragraphs (2-3 sentences each)
- Specific numbers or results when possible
- End with a question or call to action
- Add 3-5 relevant hashtags
- Tone: professional but conversational, share insights not humble-brags
- Length: 150-300 words

#### Newsletter Section Format
- Headline (compelling, specific)
- 2-3 paragraphs of insight
- Practical takeaway or lesson
- Optional: code snippet or tool recommendation
- Length: 200-400 words

#### Blog Article Format
- Title (SEO-friendly, specific)
- Introduction (hook + what reader will learn)
- 3-5 sections with H2 headings
- Code examples if relevant
- Conclusion with actionable takeaways
- Length: 800-1500 words

### Step 4 — Output

Present the draft with:
- The content ready to copy
- Suggested edits or variations
- Optimal posting time suggestion (for LinkedIn)
