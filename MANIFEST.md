# Skill manifest

The pack is deliberately curated: every included folder is intended to be
portable, while external capabilities remain optional and explicit.

| Area | Skills | Extra capability when applicable |
|---|---|---|
| Engineering | `api-design`, `bughunter`, `debugging-guide`, `full-output-enforcement`, `git-ship`, `mirror-pattern`, `quick-fix`, `refactor`, `scaffold`, `sprint-kickoff`, `tdd-workflow`, `teleport`, `ultrareview`, `webhook-guide` | Repository and terminal access |
| Multi-agent delivery | `agent-wave-verify`, `audit`, `build-feature`, `debug-swarm`, `research`, `review-and-fix`, `security-audit`, `swarm` | Multi-agent orchestration |
| Quality | `deploy-check`, `harden`, `perf-check`, `security-review` | Project-specific test or platform tools |
| Visual design | `brandkit`, `hatch-pet`, `high-end-visual-design`, `image-to-code`, `imagegen-frontend-mobile`, `imagegen-frontend-web` | Image generation; frontend tools for implementation skills |
| Landing pages | `lp-conversion-strategy`, `lp-design-build`, `lp-message-map`, `lp-verification-gate` | Node.js for bundled validators |
| Growth | `ahrefs-budget-check`, `competitor-intel`, `growth-scan`, `seo-check` | Ahrefs connector |

## Excluded from the public edition

- Personal memory capture, grooming, retrospectives, vault notes, and daily or
  weekly state
- Portfolio, company, product, site, deployment, and private brand workflows
- Personal writing-voice calibration and private publication examples
- Generated Framer project caches and project identifiers
- Deprecated design aliases
- Skills that are already distributed by OpenAI or another upstream plugin
- Local analytics logging and private incident examples
